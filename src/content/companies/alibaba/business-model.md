# 商业模式：现金机器与第二曲线

阿里巴巴的研究不能把电商、Cloud、AI 产品和芯片视为一条同质收入。FY2026 中国电商 Adjusted EBITA 为 1,075.09 亿元，是最大正向利润池；旧 Cloud 为 142.65 亿元。[`BABA-SRC-AR-2026`, PDF p.72]

## 资金与商业化链条

`电商利润池 → AI/Cloud 基础设施 → 算力与模型产品 → 客户用量 → 经营利润 → 现金回报`

前半段已有披露：Cloud 增速恢复，AI 产品收入开始可见。后半段仍缺分部资本开支、折旧、客户留存、价格/用量和自由现金流。

FY2027 新分部把 T-Head 纳入 AI Cloud and Compute。当前最可观察的路径是“芯片能力嵌入云服务”，而不是独立芯片销售；对 T-Head 单独计价会与 Cloud 重复计算。[`BABA-SRC-EARN-Q1FY2027`, PDF pp.2、6]
