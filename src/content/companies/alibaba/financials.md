# 财务观察

| 财年 | 旧 Cloud 收入（亿元） | Adjusted EBITA margin |
|---:|---:|---:|
| FY2022 | 1,020.16 | 3.67% |
| FY2023 | 1,034.97 | 3.96% |
| FY2024 | 1,063.74 | 5.75% |
| FY2025 | 1,180.28 | 8.94% |
| FY2026 | 1,581.32 | 9.02% |

来源：`BABA-SRC-AR-2026`, PDF pp.71–72、78；利润率为 Adjusted EBITA / 分部收入的研究计算。

FY2026 的增长加速很明显，但利润率只提升约 0.08 个百分点。与此同时，集团资本开支达到 1,260.63 亿元、自由现金流为负 466.09 亿元。FY2027 Q1 单季资本开支 676.78 亿元、自由现金流流出 446.70 亿元。[`BABA-SRC-AR-2026`, PDF pp.76、95；`BABA-SRC-EARN-Q1FY2027`, PDF p.14]

**边界：** 集团资本开支还包括物流、直营、土地与园区，不能全部标成 AI/Cloud；但也不能因为 Cloud Adjusted EBITA 增长，就忽略资本强度。
