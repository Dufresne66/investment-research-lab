# 阿里巴巴研究总览

> 核心问题不是 AI + Cloud 是否增长，而是增长在折旧、资本开支和持续研发之后，能否形成高于资本成本的长期回报。

## 已经确认

- **FACT：** FY2026 旧 Cloud 收入增长 34%，Adjusted EBITA 增长 35%。[`BABA-SRC-AR-2026`, PDF pp.71–72、78]
- **FACT：** FY2027 Q1 新 AI Cloud and Compute 收入增长 45%，Adjusted EBITA 增长 133%；AI 产品收入首次单列为 123.76 亿元。[`BABA-SRC-EARN-Q1FY2027`, PDF pp.3、6、8]
- **FACT：** FY2026 集团资本开支升至 1,260.63 亿元，公司定义自由现金流转为负 466.09 亿元。[`BABA-SRC-AR-2026`, PDF pp.76、95]

## 尚未确认

Cloud 独立资本开支、折旧、投入资本与自由现金流没有披露。新分部又加入 T-Head，旧 Cloud 与新口径不能直接拼接。`BABA-CLOUD-001` 与 `BABA-CHIP-001` 均保持 `OPEN`，没有人工置信度。
