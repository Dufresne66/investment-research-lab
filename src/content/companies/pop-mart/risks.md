# 风险与反证

## 会推翻“可重复 IP 引擎”的情况

1. THE MONSTERS 或下一任爆款回落后，其他 IP 无法在两个完整年度内维持组合增长。
2. Top1/Top5 集中度持续上升，增长继续依赖单一 IP 或单一产品形态。
3. 新 IP 多数只在一个发布周期放量，三年留存率低。
4. 海外 sell-through 低于出货，库存、折扣、退货或减值持续上升。
5. 主要艺术家 IP 因授权期限、非独家或分成安排而无法稳定续营。

2026 H1 亚太和美洲收入下降、库存周转升至 201 天，是需要保留的反向证据；管理层关于提前备货的解释必须由未来周转数据验证。[`PM-SRC-H1-2026`, PDF pp.24、35]
