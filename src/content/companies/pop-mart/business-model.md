# 商业模式：IP × 产品 × 分发

泡泡玛特围绕艺术家 IP 与授权 IP 进行产品开发，再通过门店、线上、机器人商店、批发及海外网络分发。长期能力不只来自角色所有权，也可能来自品牌、产品开发、渠道与合约组合。

## 三个不能混淆的层次

1. **IP 组合：** MOLLY、SKULLPANDA、DIMOO 等老 IP 与 CRYBABY、星星人等新 IP 的生命周期。
2. **产品载体：** 毛绒收入占比从 2023 年 3.2% 升至 2025 年 50.4%，2026 H1 进一步升至 57.2%。[`PM-SRC-AR-2024`, PDF p.28；`PM-SRC-AR-2025`, PDF p.29；`PM-SRC-H1-2026`, PDF p.31]
3. **分发网络：** 2025 年美洲高速增长，但 2026 H1 亚太和美洲分别下降 9.7% 与 16.5%。[`PM-SRC-AR-2025`, PDF pp.20、25；`PM-SRC-H1-2026`, PDF p.24]

年报区分收购 IP 产权与授权 IP；艺术家 IP 不应默认理解为公司完整拥有所有法律权利。[`PM-SRC-AR-2025`, PDF pp.243、298、338]
