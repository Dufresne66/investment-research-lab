# 当前研究命题

`PM-IP-001`：泡泡玛特已形成可重复的多 IP 孵化与商业化引擎，长期增长不依赖单一爆款。

多 IP 跨年运营、新 IP 接力与产品扩展支持这项命题；不断上升的 Top1/Top5 集中度、毛绒占比、海外波动和库存周转则削弱它。最关键的未知是新 IP cohort 成功率与三年留存、IP × 产品 × 地区交叉经济性，以及排除最大 IP 后的利润和现金流。

Claim 仍为 `OPEN`，人工置信度未设置。本页只记录可证伪的研究命题，不形成最终投资决策。
