# 证据驱动的公司研究

研究顺序固定为：事实 → 理解 → 假设 → 证据 → 反证 → 估值 → 决策 → 复盘。

## 三类陈述

- **FACT：** 必须能回到原始来源。
- **INFERENCE：** 必须写出从事实到解释的推理。
- **HYPOTHESIS：** 必须允许被具体证据推翻。

研究的目标不是让原判断看起来正确，而是让它有机会被现实纠正。

```text
FACT → INFERENCE → HYPOTHESIS → EVIDENCE → UPDATE
```
