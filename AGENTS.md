# Public Website Rules

This repository is the public publication layer of the Investment workspace.

- Do not place local PDF files, private reading notes, unfinished calculations, or draft investment judgments in this repository.
- Research work belongs in the sibling private repository: `/Users/dufresne/Investment/investment-research/`.
- Publish research only after the user explicitly approves a publication candidate.
- Every published fact must retain a stable source ID and a page or section locator.
- Keep `FACT`, `INFERENCE`, and `HYPOTHESIS` distinct. Preserve contrary evidence and unresolved uncertainty.
- Claim confidence and final investment decisions are human-owned.
- Run the content check, build, and rendered-page tests before pushing changes.
