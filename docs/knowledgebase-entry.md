# Investment 工作区迁移说明

> 本文件保留旧架构的迁移背景。自 2026-08-20 起，投资研究不再以 KnowledgeBase 为主目录。

## 当前工作区

本地 Investment 工作区（私人研究与公开出版两个相邻项目）。

当前工作区分为两个独立 Git 项目：

- `investment-research/`：私人研究层，管理原始资料、阅读笔记、研究问题、Claim、反证、计算、比较与判断历史；
- `investment-research-lab/`：公开出版层，管理网站代码和经过批准的公开研究内容。

KnowledgeBase 中原有投资资料按迁移清单逐批复制并核验。在核验完成前保留原文件，不直接删除。

## 当前阶段

MVP 已建立，并已用五家公司验证“私人研究 → 人工批准 → 精简出版”流程。当前不接入实时行情、交易、登录或数据库。

## 当前研究对象

牧原股份、贵州茅台、小鹏集团、阿里巴巴与泡泡玛特。

所有核心 Claim 保持 `OPEN`。只有牧原 `MY-COST-001` 保留用户原有的 40% 人工置信度；其余 Claim 尚未分配人工置信度。

## 下一步

继续按各公司尚未闭合的 Evidence gate 更新来源、反证与 Claim。缺失证据保持未知；在关键口径和资本回报没有被验证前，不进入精确估值，也不形成买卖结论。

## 阶段性沉淀

当核心命题完成一轮支持与反证检查后，先进入私人研究层的 `publication/candidates.md`。只有用户明确批准后，才整理到公开网站。
